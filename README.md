# Projectile Lab — 포물선 운동 실험실

브라우저에서 실행하는 2차원 포물선 운동 시뮬레이터입니다. HTML/CSS/JavaScript와 Canvas API만 사용하며 별도 설치나 빌드 과정이 필요하지 않습니다.

## 실행하기
1. 이 저장소를 다운로드하거나 GitHub에 업로드합니다.
2. `index.html`을 브라우저에서 엽니다.
3. GitHub Pages를 사용하려면 저장소의 **Settings → Pages → Deploy from a branch → main / root**를 선택합니다.

## 주요 기능
- 초기 속도, 발사 각도, 질량, 중력가속도 변경
- 변인 선택 후 보조 발사대에서 드래그하고 놓아 착지 거리로 값을 설정
- 정밀 값 직접 입력
- 포물선 궤적 미리보기와 시간에 따른 애니메이션
- 최고 높이, 비행 시간, 수평 도달 거리, 최고점 도달 시간 계산
- 실험 조건과 결과 저장 및 비교
- 반응형 레이아웃

## 물리 모델
공기 저항을 무시하고 발사 높이와 착지 높이가 같다고 가정합니다.

- `x(t) = v₀ cos(θ) · t`
- `y(t) = v₀ sin(θ) · t − ½gt²`
- `T = 2v₀ sin(θ) / g`
- `R = v₀² sin(2θ) / g`
- `H = v₀² sin²(θ) / (2g)`

이 모델에서는 질량이 운동 방정식에 나타나지 않으므로, 질량만 바꾸면 궤적은 변하지 않습니다.

## 조작법
- 오른쪽의 변인 목록에서 조절할 변인을 선택합니다.
- 발사대 캔버스에서 공을 끌어 조준하고 마우스/터치 입력을 놓습니다.
- 조절용 발사체의 착지 거리가 선택된 변인의 범위에 대응합니다.
- 필요하면 정밀 값 입력란에서 수치를 직접 입력할 수 있습니다.
- **현재 조건 저장**을 누르면 실험 비교표에 결과가 추가됩니다.

## 파일 구성
- `index.html`: 화면 구조
- `styles.css`: 디자인 및 반응형 스타일
- `app.js`: 물리 계산, 캔버스 렌더링, 인터랙션
