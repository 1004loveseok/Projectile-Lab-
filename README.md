# Projectile Lab — 포물선 운동 실험실

한 사이트에서 두 가지 방식으로 포물선 운동을 경험하는 교육용 웹 프로젝트입니다.

## 두 가지 모드

### 1. 물리 실험실
- 초기 속도, 발사 각도, 질량, 중력가속도 변경
- 보조 발사대의 드래그 조작으로 변인 설정
- 정밀 수치 입력
- 포물선 궤적과 운동 애니메이션
- 최고 높이, 비행 시간, 수평 도달 거리, 최고점 도달 시간 계산
- 실험 조건과 결과 저장 및 비교

### 2. 포물선 챌린지 (LEVEL 1–10)
- 발사 각도와 세기를 조절해 목표물을 맞히는 아케이드형 물리 퍼즐
- 레벨마다 목표 위치와 장애물 배치가 달라짐
- 마우스 또는 터치로 발사대를 드래그해 조준
- 각도/세기 슬라이더와 직접 조준을 모두 지원
- 레벨 클리어 시 다음 레벨 해금
- 재시도, 레벨 선택, 발사 횟수 표시

게임 모드는 만화풍의 공과 빛나는 목표물을 사용하는 비폭력 퍼즐 방식이며, 실제 물체나 장치의 사용법을 안내하지 않습니다.

## 실행하기
1. 저장소 최상위에 `index.html`, `styles.css`, `app.js`, `README.md`를 업로드합니다.
2. `index.html`을 브라우저에서 열면 바로 실행됩니다.
3. GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**를 선택합니다.

## 물리 모델
실험실은 공기 저항을 무시하고 발사 높이와 착지 높이가 같다고 가정합니다.

- `x(t) = v₀ cos(θ) · t`
- `y(t) = v₀ sin(θ) · t − ½gt²`
- `T = 2v₀ sin(θ) / g`
- `R = v₀² sin(2θ) / g`
- `H = v₀² sin²(θ) / (2g)`

이상적인 포물선 운동에서 질량은 궤적에 영향을 주지 않습니다.

## 파일 구성
- `index.html`: 두 모드의 화면 구조
- `styles.css`: 디자인 및 반응형 스타일
- `app.js`: 물리 계산, Canvas 렌더링, 실험실 및 게임 상호작용
